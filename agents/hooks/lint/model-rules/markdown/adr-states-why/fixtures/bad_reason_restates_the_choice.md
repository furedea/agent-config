# Adopt a hexagonal architecture

## Context and Problem Statement

We need to decide how to structure the application.

## Considered Options

* Hexagonal architecture
* Layered architecture

## Decision Outcome

Chosen option: "Hexagonal architecture", because it is the best option and it is the right architecture for this
application. It is the most suitable choice for our needs, and it fits what we are building.

### Consequences

* Good, because the application has the right architecture.
* Bad, because there are some downsides.
